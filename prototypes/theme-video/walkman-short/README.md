# ここのベース、好き。

[日本語ショートを再生](hotline.ja.mp4)（31.5秒、縦9:16、720×1280、30fps、ステレオ）

ヘッドホン越しに曲を聴く側に、観客の耳を置いた。小声で何か言った人が、オレンジのボタンを押したあと、同じことをもう一度言う。そのひと言をきっかけに、さっきから鳴っていたベースが耳に残る。

## 元の横長回との関係

[ウォークマンの横長回](../walkman/README.md)の人物とプレーヤーの原画、番組の四音を共用。縦版用に会話と楽曲を書き、二本のコード、マイクの近くを通る声、テープの中の小さなコントラバスを描いた。横長回では、そのボタンを思いついた場面を盛田昭夫の回想からたどれる。

## 資料とクレジット

- マイクを働かせて、同じ機械につないだ二人が音楽を聴きながら話せる仕組みと「ホットライン」の命名は、盛田自身の回想による。[盛田昭夫「ウォークマン考」](https://bunshun.jp/articles/-/5676)
- 製品は1979年のソニー TPS-L2。[ソニーの商品史](https://www.sony.com/ja/SonyInfo/CorporateInfo/History/sonyhistory-e.html)
- 会話、音楽、聞こえ方、本体の図は機能を伝える演出。楽曲と効果音は本作用の合成音。
- 音声　VOICEVOX:青山龍星、VOICEVOX:春日部つむぎ、VOICEVOX:玄野武宏

## 書き出し

Windowsで Python、Pillow、NumPy、SciPy、requests、resvg-py、FFmpeg を使用。游明朝・游ゴシック・Georgia をシステムフォントから読む。VOICEVOX Engine をローカルの13769番ポートで起動し、このフォルダーで `python render.py` を実行する。音声キャッシュはOSの一時領域に置き、画面編集時は `python render.py --audio-ready` で同じ音を使える。
