# Plunode の作品見本

**ウォークマン**　冒頭はヘッドホンをつけた二人の間に一台の機械があり、最初の四音が鳴ります。29秒ごろ、本体のリールが二つの目に見えます。左に出典を置く画も、この場面のために選んだ構図です。72秒ごろは、暖色の線がコードに沿って隣の人の耳に届きます。[映像](walkman.mp4) ／ [実際の字幕](walkman.ja.srt)

**キャベツ畑まで、2.5秒。**　キャベツを一株見るところから始まります。25秒ごろ、点火しても機体はまだ架台にいる。続く飛翔では声を休め、飛んだ後に距離を聞かせます。43秒以降、同じ動きが日記を書いた人とそれを見ていた人で違って見えてきます。[映像](goddard.mp4) ／ [語り・読み・開始時刻](goddard-script.json)

絵を見比べたいときの静止画と、次の作品でも使える番組のチャイムがあります。[画の見本](frames.jpg) ／ [冒頭の四音](opening.wav)

## 絵の作り方を見たいときに

ウォークマン回の冒頭と本体の寄りは、同じ一枚の原画から切り出しました。二人の横顔からコードをたどると、二つの目にも見えるリールに行き着きます。SVGを開くと一枚全体を眺められます。[ウォークマン回の原画](listen.svg)

ゴダード回では、実際に使った描画コードでキャベツの外葉の重なりや葉脈、遠くの畝を描いています。場面を組んだコードでは、同じ絵が点火の前後でいつ、どの大きさで見えるかを読めます。描き方や動かし方を探るときに、それぞれの作品で選んだ一例として参照できます。[キャベツと畑の原画](art.tsx) ／ [動きと編集](film.tsx)

## 各回に共通する意匠

Plunodeのロゴは [明るい地に置く版](brand.png) と [暗い地に置く版](brand-light.png)。ウォークマン回で使った色は、紙色 `#f5f1e7`、濃紺 `#172936`、青 `#235c85`、橙 `#d57532`。見出しは明朝系、字幕は読みやすいゴシック系です。ゴダード回の畑では同じ紙の温度感のなかに土やキャベツの色が入ります。導入の四音にどの絵を合わせ、どのくらいその絵にとどまるかは作品ごとに選べます。

## 依頼と試写の言葉

ウォークマン回を見た運営者の言葉に「入りのチャイム音も良かった」「あの入り口の空間が心地よかった」とあります。出典を見せるときのサイド表示も好評で、毎場面同じ場所に出続ける構成を気にしていました。ゴダード回の依頼は「自由にテーマを選んで、コンセプトに沿った動画を生成してくれませんか？」「案もお任せします」。完成版への感想は「これまでの最高品質です」でした。
