# テレビの実験相手

[日本語の冒頭を再生](opening.ja.mp4) ／ [localhostの制作室で再生](http://127.0.0.1:3269/samples/baird-opening.ja.mp4)

1925年のロンドン。ベアードが顔の明暗まで送るテレビの実験に使ったのは、腹話術の人形の頭だった。そのあとで呼ばれた青年ウィリアム・テイントンは、階段を駆け下りてきた発明家のだぶだぶのズボンと、靴下を履かずにつっかけた室内履きを覚えていた。原資料は人形から青年の顔への順序と、青年自身が覚えていた足元を伝えている。[English Heritageの解説とテイントンの回想](https://www.english-heritage.org.uk/visit/blue-plaques/john-logie-baird-television/#first-pictures) ／ [Science Museum Groupの送信装置の所蔵記録](https://collection.sciencemuseumgroup.org.uk/objects/co35907/john-logie-bairds-original-experimental-apparatus-television-equipment) ／ [Plunodeのテレビ公開第25版](https://plunode.net/?ktheme=theme%3Aab27f44d7a9c30ca358776922779f9ad2bac4f83ad860eee&krev=25)

## 二枚の絵で試したこと

- [人形と装置](dummy.png)は、横顔と円盤を同じ高さに置いた。一方が実験の被写体で、一方が機械なのに、互いを観察しているようにも見える。ウォークマン回で運営者が挙げた、本体の部品が顔に見える一枚を手がかりにした。装置は所蔵資料の円盤やレンズから形を取った演出図。各部の位置や光路を説明する用途には使わない。
- [階段の足元](stairs.png)では、今度は人の顔を映したいという場面で、あえて足元を大写しにした。原画の初稿には階段の上に人形が残っていた。説明を伏せたAIの読み返しで「人形が見送っている」と読めたので、人形の居場所まで実話に見える要素を外し、後ろ足のかかとと大きな室内履きを残した。服装と階段は回想、色・構図・かかとの角度は演出による。

二枚の原画は運営者が示したウォークマンの画面を作風の参照にして画像生成し、脚本・画の採否・間を今回の制作で編集した。制作室の切り口を空欄にして得た自動生成結果との比較には、別の新規案件を使う。

## 音の入り方

最初のフレームから人形と装置を見せ、ウォークマン回と同じ四音（ファ・ラ・ソ・ド）を重ねた。0.08秒に一音目、1.03秒に四音目。約1.08秒に「テレビの実験で」の声を置いた。絵を眺めているうちに話が始まる入り方を試している。チャイムはPlunodeで合成した音。日本語の声はVOICEVOXの青山龍星（ノーマル）。[ウォークマンの音付き見本](../walkman/walkman-pilot.mp4) ／ [共通の音の生成式](../channel_sound.py)

## 試写で分かったこと

制作意図を伏せて映像と字幕を見たAIは、人形から人間へ実験相手が変わったと読み取り、橙色の室内履きと素足を挙げた。一方、「実際の画面には人形の顔がどう映ったのか」も知りたくなったという。一本に育てるなら、この問いを回収できる史料を探し、実験の日付と画像の来歴を確かめる。入り心地については、音付きで観た人の感想を優先する。

最終版は22.875秒。字幕の「室内履き」に読み「シツナイバキ」を指定して再出力し、映像549フレーム、冒頭の四音と日本語の五つの発話が最終ファイルに入ったことを照合した。

制作室と同じWindowsの音声・フォント・FFmpeg環境で、リポジトリのルートから次を実行すると書き出せる。語り、絵の切替、余韻の位置は編集用スクリプトの `LINES` にある。[描画・音声・字幕の編集表](render.py) ／ [制作室の起動環境](../studio/README.md#起動)

```powershell
python -B prototypes/theme-video/baird/render.py
```
