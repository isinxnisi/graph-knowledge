# 監督・出演Roleの意味契約案
状態：提案・未承認。正式catalog／enum／baseline／approvedレビューは変更していない。

[機械可読案](role-proposals.json)に定義、日英表示語、包含・除外・境界例、既存8Role＋新Role間の全比較を保存した。DIRECTINGとACTINGはいずれも人物→作品のCONTRIBUTED_TO限定で、新Predicateではない。出演一般を広く意味するCASTを採用せず、演技担当を意味するACTINGを提案する。

| 問題 | 本案の扱い |
| --- | --- |
| 監督と監修 | DIRECTINGとSUPERVISIONは別。既存監修Claimを変更しない |
| 総監督・共同監督・追加撮影 | 包含文字列では変換しない。全体監督としての共同担当は個別審査。総監督の責務不明・限定工程・追加撮影のみは保留 |
| 実写の演技出演 | 人物・対象作品・役柄／演技担当を資料文脈で確認して候補化 |
| 声・吹替・アーカイブ・本人登場 | ACTINGへ自動統合しない。別Role候補又は未対応として保留。アーカイブ出演は直接制作を意味しない |
| 作品と版 | 現行publication scopeを映画に流用しない。作品単位で資料が明示する候補のみscope:null。cut、言語、地域限定はsidecarに残し、表現が必要なClaimは保留 |
| null scope | 未構造化。全cut・全地域・全期間でも、限定なしを確認済みでもない |
| 年・期間 | 同定用の作品年と上映日・制作期間は別。公開年をperiodへ補完しない |
| Wikidataのみ | P57/P161は候補発見・照合用。原資料確認済みと独立支持数に数えない |
| Source/Citation | URL、locator、言語、取得日、短い原役割語、対象人物・作品との対応を保持。原文未保存はnullのまま |

映画に閉じたIDを避け、同じ意味を持つ舞台等にも将来再利用可能とした。ただし今回の証拠は映画3作品に限定し、他領域への適合を検証したとはしない。

今回の実装は段別Role検索のみを共通コードへ追加する。映画Roleの実行は scripts/test-film-step-roles.py が作る一時ソースコピーでenumと表示語を拡張する。既存catalogの審査ゲートを弱めず、機械生成のapproved票を人間承認として扱わない。通常checkoutはDIRECTING／ACTINGを拒否する。

採用時は本案の包含範囲を人が判断し、実際のレビュー担当者・日時・定義hashを登録する。catalog、enum、日英表示を同時更新し、基準版を変更せず vocabulary:check の採用前SHA比較を通す。研究データの正式受入はその後も別判断である。
