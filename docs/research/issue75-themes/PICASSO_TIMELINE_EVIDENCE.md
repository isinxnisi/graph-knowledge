# 青の時代：時期と明示関係を分ける実テーマ

2026-11-01。[picasso-blue-period.json](../../../public/theme-examples/picasso-blue-period.json) は通常パッケージ形式の実資料サンプル。6対象・6記録で、1期間、1制作時期の幅、2件の年単位の制作、2件の明示的な分類関係を比較する。作品画像の転載は含めない。

## 根拠と採用範囲

参照先はいずれも美術館の公式資料。確認作業後に時計で記録した `2026-11-01T07:25:10Z`（日本時間16:25:10）を `retrievedAt` に用いた。資料自体の作成日時、作品制作日時とは区別する。抜粋欄は日本語での短い要約を基本とする。

シカゴ美術館の通常作品ページはこの調査では403となったため、本文を読めた同館公式の来館ガイドPDFを採用した。検索結果だけで本文確認済みとはしていない。マティス作品は旧資料に1904〜1905年などの表記もあるが、今回の記録は現行作品台帳の採用値を根拠とする。資料間の年代比較を解決したとはしない。

## 時間の入力に伴う編集判断

- `duration` は青の時代という時期区分に使う。1901・1904は年精度であり、1月1日・12月31日の史実を主張しない。この美術史上の区分がピカソの全制作を排他的に分類するとは扱わない。
- 《老いたギター弾き》の `occurrence-window` は制作年代が一時点に確定しない範囲。`from: 1903` / `to: 1904` とし、元資料の「年後半」「年初」はラベルと範囲に残す。後半を7月1日、年初を3月31日などへ変換していない。1903〜1904年ずっと制作を続けたという `duration` にはしない。
- 《生》とマティス作品は年精度の `point`。年内の正確な制作日や作業時間は主張しない。マティス作品の季節表現もラベルに保持し、勝手に暦月へ割り当てない。
- 作品と青の時代を結ぶ2関係は、美術館の明示的な説明を独立した記録にする。これは1901〜1904年の時間帯への配置から生成した関係ではない。分類そのものの有効開始日・終了日は付けない。
- マティス作品は比較のため同じ年表へ置く。青の時代への所属・影響関係は登録しない。関係がないことを証明したわけでもなく、未登録を `denied` へ変換しない。

今回の参照資料は、青の時代の最も早い開始・最も遅い開始・最も早い終了・最も遅い終了という四境界を支持していない。そのため `startLatest` / `endEarliest` を実テーマへ加えていない。年精度や作品の制作時期の幅を、期間の境界不確かさへ置き換えない。境界不確かさの操作確認は、史実と混ざらない別の「操作例・架空」のfixtureで扱う。

### 別パッケージの架空操作例

[temporal-boundaries-example.json](../../../public/theme-examples/temporal-boundaries-example.json) に3件の操作例を分離した。タイトル・説明・全具体文・根拠欄で架空と明示する。根拠URLはこのPCの同JSONを指し、外部資料ではなく例の定義を開くための参照。`retrievedAt` は定義作成時に記録した `2026-11-01T07:27:19Z` で、実資料の取得時刻ではない。

| 操作例 | 入力 | 読み分ける点 |
| --- | --- | --- |
| 架空展示A | 開始候補1/1〜1/15、終了候補3/1〜3/31 | 開始・終了それぞれの候補幅と、その間の継続を分ける。 |
| 架空展示B | 開始候補2/1〜2/20、終了候補2/10〜2/28 | `startLatest > endEarliest` で候補幅が交差する。すべての候補に共通する継続区間があるとはしない。実際の終了が実際の開始より前になる組合せは採らない。 |
| 架空確認C | 2/5〜2/18のどこかの一時点 | `occurrence-window` は実施時期の候補範囲。作業の継続期間やA・Bへの所属関係ではない。 |

架空の日付はすべて2024年。ピカソの実資料とはテーマIDも対象も分けた。これらの数値を美術史上の不確かさの幅へ転用しない。

## 通常の取込で試す内容

1. 6記録を同じパッケージ取込経路で登録する。テーマ専用のコードや分類ENUMは不要。
2. 年表で時期区分、制作時期の幅、年単位の制作を読み比べる。
3. 関係図で《老いたギター弾き》《生》から青の時代への明示関係を確認し、マティス側には自動生成されないことを確認する。
4. 作品の制作だけ、または制作と分類の両方を選択してCapsuleに保存し、選んだ記録の違いを確認する。

資料の選定・翻訳・日本語作品名・対象の同定・制作と分類の分割・時間値の意味の判断は、今回エージェントが人の編集に相当する作業として補った。自動抽出の性能実証ではない。関係の否定や因果を追加せず、意味マッピングは未設定。

この文書は資材と出典の記録で、実ブラウザ操作や取込結果の完了記録ではない。登録時間は未実測。DBへの取込・Capsule往復は主担当の隔離確認環境で行い、結果を別の検証記録へ残す。main／3200／HTTPS β／本番への反映は対象外。

資材単体では両パッケージのJSON・対象／記録参照を照合し、更新後の `themePackageSchema.parse` に通した。ピカソ6記録、架空3記録とも成功。実資料側に境界幅を捏造していないこと、マティス作品から青の時代への所属関係がないことも確認した。
