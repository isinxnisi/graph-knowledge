## 判明した構造

- **ジャンルを跨ぐ脚本家の接点**：ブレードランナー → David Peoples → 許されざる者。Hampton Fancher経由では2049へ進む。同じ2段でも別の発見になる。
- **役割を変えて辿る問い**：許されざる者 → 出演者Clint Eastwood → 監督作品ミリオンダラー・ベイビー。段ごとの指定なら1経路。全段「出演または監督」では7経路・2作品に広がり、目的外の根拠が混ざる。
- **複数の共通点**：インセプションと監督・音楽担当の両方が共通する対象は、今回の集合ではインターステラー。ORの3作品を返すだけでは同じ問いに答えない。
- **原作を介した横断**：Dune 1984 → 小説Dune → Dune 2021。同じ原作であることは映画同士のリメイクを証明しない。
- **3段で次の人物へ**：ブレードランナー → 脚本家 → 別映画 → 出演者は7経路。既存のwork-creatorsの形を使い、各段のRoleを変えるだけで具体的な用途が生まれる。

## 現行との差

現行の人物→作品、独立Claim、Citation、2〜3段の版付き経路形は再利用できる。脚本・製作の既存Roleへの投影は構文上成立するが、映画への意味契約・受入は別途必要。監督・出演・音楽・撮影Role、映画版scope、work→workの由来関係、段別Role、同じ終点へのAND条件は不足する。

純粋domain実装を隔離データで実行し、正負10検証が成功した。役割を消した**形・上限だけの比較**ではブレードランナーの3段23経路が現行上限で12経路となり、`results` が返る。これは全体検索の不存在判定ではない。研究用コールバックで段別Roleを課すと目的の7経路を得た。DB・HTTP検索実行・UIの改修や性能評価はしていない。

公開KGの名前20条件と歴史snapshot／正式受入10 receiptを読み取り照合し、今回97候補との一致は検出しなかった。検索した名前以外の収録を否定する結果ではない。旧資料の「未公開1 Claim」は現在APIで公開確認でき、古い未公開状態を引き継がなかった。映画候補を公開結果へ混ぜていない。

## 第一候補の改善案と人間の判断事項

第一候補は、**監督・出演の限定Role契約と、既存other-worksに段別Roleを加える小さな版追加**。プリセットを大量追加する前に「出演→監督」の2辺を完全な根拠として返せるかを確かめる。脚本家経路は現行構造を活かす比較基準にする。

採用前に判断する点：

1. 監督と総監督・追加撮影、出演と声の出演／吹替／アーカイブ出演をどこまで分けるか。現行SCRIPT_WRITING／PRODUCINGを映画にも使う意味契約を確認する。
2. 作品全体・特定cut・地域公開版の粒度。scope不明を「全版で成立」と扱わず、原資料の対象版を保持する。
3. 段別Roleを条件schema・検索・witness・Graph復元へ一貫して渡す新版の範囲。旧版の全段共通OR条件と互換を保つ。
4. BASED_ON／SEQUEL_OF／SERIES_MEMBERSHIPの定義、直接／間接由来、series Entityの粒度。リメイクは別に保留する。
5. ACMI側のWikidata由来の可能性と人物同定を含む、人間の資料・意味レビュー。到達数を確信度や優先度の自動得点にしない。

次に実装するなら、上記1〜3の採用範囲を決めたうえで、今回の反例を契約テストに使う。最初は2段の異なるRoleに絞り、同終点AND・作品間Predicate・分類検索は次の判断単位とする。収集は保存済み資料から進め、全作品の取り直しや既存Workerの拡張を前提にしない。
