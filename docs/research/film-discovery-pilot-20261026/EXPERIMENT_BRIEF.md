# 洋画の知識Graph・探索モデル研究 — 独立パイロット（2026-10-26）

状態：**研究実施用の指示書。実データの収集・受入・本番公開の完了記録ではない。**
担当候補：**Codex / Astra・高（単一モデル）**。
既存の収集Worker、承認・正式受入・公開フローとは独立して行う。

## 目的
洋画を題材に、実資料から作品・人物・役割・作品間の関係を構造化し、ユーザーが「どんな条件で、どんな関係を追いたくなるか」を探索モデルとして導出・検証する。単なる映画の収録件数拡大や、プリセット数増加を目標にしない。

1. **データ収集・根拠**：洋画8〜12作品程度を選び、監督・出演・脚本・その他の役割、作品の同一性、シリーズ／リメイク／翻案の関係の根拠候補を調べる。各主張について元資料、同定、粒度、確認状態を記録する。
2. **既存KGとの対照**：公開済みKGと正式受入済み未公開の記録を別状態として読み取り照合する。候補データ、保留データ、既公開データを混ぜて「探索可能」としない。
3. **意味モデルの検討**：現行Entity kind／Predicate／ContributionRole／scope／Citationで何が表現できるか、欠けるものは何かを例付きで検証する。出演や監督等を漫画の既存Roleへ偽装しない。映画単体とシリーズ、原作と映画化、版・公開年を混同しない。
4. **探索条件の体系化**：現行の2〜3段探索・関係条件で成立するパターンと、段ごとの役割指定、作品分類、異種Predicateの組合せ、条件付き候補検索など不足する能力を区別する。少なくとも具体的な問いと証拠付き経路を複数提示する。
5. **小さな実証**：現行モデルで成立する経路／追加条件で新たに成立する経路を、代表例・評価基準・上限による欠落とともに比較する。グラフ表示について実データ上の要件・可能性を整理してよいが、Graph描画の実装は必須ではない。

## 初回の実行範囲と費用
- **Astra・高の一本化**。同じ資料を別モデルに再調査・再設計させる比較はしない。外部AIモデルやエージェントを追加起動しない。
- 8〜12作品の多様性（年代、監督・出演・脚本、シリーズ／単独作品）を優先する。研究者自身が根拠のある対象を選択し、選定理由と調査打切り条件を記録する。必要以上に拡大しない。
- 出典取得は一度だけ行い再利用する。公開APIや再利用可能な構造化ソースを起点とし、根拠の信頼性・利用条件を確認する。非商用専用、二次配布不可、資格情報が必要なDBを無断で組み込まない。Raw全文／映画画像等を無断複製しない。
- ソースが不足した主張は保留する。出典不明のもっともらしい関係をClaimとして昇格させない。

**映画研究での具体的な評価**：
- 収集した関係に対して「追加のClaimがある」と「新しい対象・経路に到達できる」を分け、2〜3段の実証経路・Role・Citationを記録する。
- 現行検索／表示上限による「未発見」を「経路なし」と誤判定しない。現行の版付き検索で確認できた経路と、研究用の推定経路は別表示にする。

- 旧レポートの数値・公開revisionは**過去の観測**であり、最新KGの現在値として引用しない。現行公開・受入状態は研究開始時に読み取りで再照合する。

## 比較・判断方法
モデル間の競争ではなく、**現行Plunodeに対する追加価値**で評価する。

| 判断観点 | 根拠・成果 |
| --- | --- |
| 事実と根拠 | 候補Claim・正確な出典・同定・保留理由の対応 |
| 構造の発見 | 少なくとも複数の異なる関係／Roleの組合せと探索の問い |
| 実装能力とのギャップ | 現行APIで成立／データ不足／モデル不足／検索能力不足を区別 |
| ユーザーの価値 | 実際に辿れる代表経路、発見の意外性、英日名称での入口 |
| 費用・継続性 | 自動バッチ化できる収集・検証と、人間の意味判断が必要な点の分離 |
