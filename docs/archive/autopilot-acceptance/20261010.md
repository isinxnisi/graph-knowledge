## 残る課題・試せる範囲

通常画面の「Capsuleを作る・読む」でブラウザ内の保存・編集・根拠閲覧を試せる。会員機能は`npm run test:member:e2e`で隔離検証できるが、終了後に試験用アカウント・保存内容は残らない。実Google設定、公開環境のmigration／cookie／ログ・頻度制限／保持削除・通報／運営非表示の判断は公開前に必要。

会員ブラウザ試験のKG応答はfixtureであり、実KGと会員保存を組み合わせた受入を代替しない。現行UIは保存ビュー・探索途中保存・Capsuleが別入口なので、用途の説明・導線には整理の余地がある。共有リンクは知っている人が再転送でき、停止しても既取得コピーは回収できない。過去のKG内容を固定するものでもない。
