# 曖昧な発生時期の表示整理（2026-11-13）

## 意図と問題

黒澤テーマの1960〜1969年は、出来事がその期間続いたという意味ではなく、その間のいつかに起きたという `occurrence-window`。開始側へ原資料向けの詳細ラベルを流用し、後端へも時期ラベルと「この日までのどこか」を重ねていたため、別の出来事や活動の終了のように読めていた。

## 修正

- 閲覧用の時期表記を「1960〜1969年のどこか」（英語 `Sometime in 1960–1969`）に整理。PCの小さい補足とスマホの日付行に同じ表現を使う。
- 閲覧モードの発生時期の後端は、日付と元の破線・丸い端だけを表示。出来事名と「この日までのどこか」は繰り返さない。
- 終端から同じRecord／時期を開く操作と読み上げ用の説明を維持。実際の期間（連載等）の終了ラベル、範囲の座標・点／期間の判定は変更しない。
- 原資料の表記・時期のラベルは保持し、詳細の「記録情報」で確認できる。登録データ・API・DB・審査は変更なし。
