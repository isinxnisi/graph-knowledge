隔離3210は既存public-kg確認KGを読む匿名開発プレビュー。既存Google／Cookie設定を置換せず、IndexedDBの保存を検証した。実Googleで成立した既存本人セッションによる会員保存は、後述のHTTPS βで別に確認した。

保存失敗・応答不明・本人再確認・失効・別本人・遅延応答・IMEイベント・履歴・表示寸法差・メニューの端とフォーカスは機能テストでも検証した。CUAの文字入力はネイティブ日本語IMEそのものではないため、実OSのIME変換操作を検証済みとは扱わない。スマートフォン実機と人間による品質評価も別途。
