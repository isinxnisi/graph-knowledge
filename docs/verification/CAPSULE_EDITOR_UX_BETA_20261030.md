## 検証の区分

隔離3210は既存public-kg確認KGを読む匿名開発プレビュー。既存Google／Cookie設定を置換せず、IndexedDBの保存を検証した。実Googleの会員保存はHTTPS βで別に確認する。

実ブラウザで、Graph→作成→タイトル変更→独自Entity・説明・根拠・分類→書式付き複数行テキスト→複数選択移動→Undo／Redo→明示保存→My Capsules→再訪→閲覧配置変更→編集→破棄を続けて操作した。右クリックは複数選択を保ち、関係は図から直接編集できた。1440px幅から390px幅に変えても中心と倍率を保ち、右ペインは狭幅で開閉できた。

保存失敗・応答不明・本人再確認・失効・別本人・遅延応答・IMEイベント・履歴・表示寸法差・メニューの端とフォーカスは機能テストでも検証する。CUAの文字入力はネイティブ日本語IMEそのものではないため、実OSのIME変換操作を検証済みとは扱わない。スマートフォン実機と人間による品質評価も別途。

## DBの復旧・再実行

既存βPGの同一read-only exported snapshotからcustom dumpと32tableの全行fingerprint・ledgerを採取。専用PostgreSQL containerへ復元し、全table・全行・000〜012のchecksumを照合した。

- dump SHA256: `1154f3787adeed8fffd79012c505b07f86f63f0a060773e6fad3e97527817a53`
- 013 SHA256: `6ef50adbb4a17d9480ef5faf0bde84247d63f99c032521c4a449491843365430`
- 復元先で013を明示適用しledger13→14。既存行はledger以外すべて一致。再実行は全行・ledger不変。
- 実PostgreSQLの会員integration33件、Capsule文書integration14件成功。新規受付ON、未作成thread、既存OFF保持、共有summaryの本人分離と失効を含む。
- 検証用containerを撤去し、既存12containerのID・開始時刻を保持。dump・設定・詳細結果はGit対象外のprivate backupへ保管。
