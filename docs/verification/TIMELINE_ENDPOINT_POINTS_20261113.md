# 曖昧な開始・終了端の点への集約（2026-11-13）

## 判断と修正

開始端・終了端をそれぞれ、その年／月／日に含まれる細かい日付との関係で判断する。期間全体を点に変換する変更ではない。

| 実例 | 表示上の処理 |
| --- | --- |
| PLUTO・1964〜1965年の連載の開始端 | 1964年内の細かい記録がないため、開始の記録と同じ位置へ集約 |
| 同じ連載の終了端 | 1965-05の改題があるため、1965年内の幅を保持 |
| 黒澤テーマ・1960〜1969年の発生時期の両端 | 各端の年内に細かい記録がないため、それぞれの開始・終了位置へ集約 |

最早・最遅の値が明示的に異なる境界はその幅を保持する。原文、時期の意味、日付精度、範囲の開始／終了値は書き換えない。以前確認した「同一日の範囲と点を描き分ける」4例も保持する。

`calendar-graph.ts` は時点・同値の発生範囲を点へまとめていたが、異なる両端を持つ期間では、各端の日付精度を常に最初から最後まで展開していた。さらに、不要な境界からも日付行を作っていた。

細かい日付が内側にあるかの判定を共通化し、開始端・終了端へ独立に適用。実際に使う境界座標だけから行を構築する。テーマとCapsuleが共用する描画モデルの変更であり、保存・取込・審査の変更ではない。
