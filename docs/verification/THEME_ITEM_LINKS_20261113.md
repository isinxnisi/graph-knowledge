## 変更

- 「配置の試作を比較」のUI、2つのstate・切替分岐・itemEntry queryによる導入部プレビュー・専用teaser部品／CSSを撤去。深く読むの一覧は図の下へ固定。

- カードは購入リンクではなくEntity・記録の詳細への操作。Entity／関係／出来事／説明の明示的な商品紐づきを扱う。テーマそのものにしか紐づかない商品は、この欄で任意のEntityへ推測して表示しない。

- テーマ側のEntity・関係／出来事詳細の商品欄は既存経路を維持。関係・出来事の詳細APIから同じ登録商品を読めることを回帰確認。
