# 初回サイドバーとTOP紹介テーマの配置（2026-11-14）

## 反映内容

- 左検索サイドバーは初回訪問・保存値なし・保存領域利用不可時に閉じる。明示的に保存されたfalse（開く）は維持する。headの初回描画前bootstrap、hook、別タブ同期の既定を揃えた。
- CSSも保存されたfalse以外は閉じるため、初回描画で開いた状態を挟まない。既存のブラウザ内保存キーは変更しない。
- テーマ中央の「テーマの出典」を、深く読む欄・関連アイテムより後ろの最終要素へ移動。出典内容や既存の開閉は維持。
- **TOP画面の紹介テーマ**の横スクロールを廃止。実際に使える欄の幅に応じるcontainer queryで、560px未満は1列、560px以上は2列、880px以上は3列とする。
- 1列時は最初の3件を表示し、4件目以降を「もっと見る／閉じる」で開閉。2〜3列では全件を並べ、開閉操作は出さない。テーマの順序・実URL・画像・短い紹介・版付き遷移は維持。
- TOPの運営プレビューも同じ部品。タブレット幅のTOPでも、もともと不要な右ペインの列を確保せず、紹介欄が利用可能な幅で折り返す。
