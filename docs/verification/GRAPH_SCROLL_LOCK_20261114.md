# Graphの初期スクロールロック（2026-11-14）

## 意図と操作

Graph上を通るページのスクロールを初期状態では図へ渡さない。本線KG・テーマ・共通知識・Capsuleなどが利用するGraphCanvasで共通化し、表示倍率や配置の保存内容は変更しない。

- 初期表示と探索世代の切替時はロック。図の透明な入力面で短いタップ／クリックを受けたときだけ解除する。最初の操作は解除に使用し、意図しない選択・移動は行わない。
- 8 CSS px以上の移動、500ms以上の長押し、複数ポインタ、pointercancel、画面外へのリリース、ウィンドウのフォーカス喪失では解除しない。移動後に開始地点へ戻っても解除しない。
- 入力面はpreventDefaultやpointer captureを使用せず、通常のページスクロールとブラウザのピンチを通す。ロック中はCytoscapeへ直接ジェスチャーが届かない。
- 右上の小さな施錠／解錠アイコンで再ロックできる。既存の表示操作パネル・図内のナビゲーションは透明面より上にあり、初期ロック中も使える。
- 解除後は従来のホイールズーム、タッチ移動、選択、ダブル操作へそのまま戻る。ホイールの倍率計算や各経路の詳細表示処理は変更しない。
- 同一Graph内の選択・拡張では勝手に再ロックしない。DB・Worker・本番は変更しない。

## 検証

- 短いtouch／mouse操作、ドラッグ後の復帰、取消、長押し、複数指、範囲外、blur、右クリックの入力判定を試験。
- GraphCanvasで初期ロック中の拡大操作、解除、再ロック、選択時の継続、探索世代変更時の再ロックを試験。
- 関連62件中61件成功。既存の「選択した対象とテキストのまとめ移動を一度の操作として通知する」1件は、変更前HEADのGraphCanvasでも同じ不一致（text位置0,0）が再現する。今回の入力ロックとは分け、既存挙動や試験の期待値を無断で変更しない。
