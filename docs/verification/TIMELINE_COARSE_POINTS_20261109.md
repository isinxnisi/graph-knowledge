# 年・月精度の出来事を点として表示する是正

## 原因と範囲

2026-11-09指摘の正式Webb Theme構成版6を公開APIから照合。1989-09／1996／2002／2004／2019の記録はいずれも `meaning:point`、`from` だけで、終了を登録していない。誤登録や新しいTheme APIによる変換ではなく、共有描画 `calendarGraph` が粗い年月の可能範囲を日表示へ投影し、時点まで範囲へ広げる欠落だった。

以前の修正は年・月表示の同一bucketへの投影だけを確認し、日付精度が混在するauto／dayの年・月時点を点として保つ契約が不足していた。既存テストにも年精度の点を日表示で2端へ広げる期待値が残っていたため、実装と合わせて訂正した。

時点はどの表示単位でも単一anchorと元精度ラベルにする。意味のない終端だけでなく、元の範囲計算が残していた空の境界行も作らない。発生候補幅／旧未区別範囲で両端が同じ原表現の場合も点化するが、保存した意味を時点へ変換しない。実期間と異なる端を持つ候補幅は維持。原本・取得版・Capsule／共有の保存データは変更せず、通常ThemeとCapsuleが使う共通描画を修正する。DB migration・Worker・Kev・AI枠の変更なし。

## 検証

calendarGraph／通常KnowledgeTimeline／ThemeTimelineの32件と変更対象lintを確認。auto・年・月・日・時間で月／年の時点に終端行を作らず、原本JSONが不変で、実期間の線と終了側は保つ。最初のUI試行では終了ボタンの空白を仮定したテストが不一致となり、表示テキストとbuttonの存在の検証に修正した。
