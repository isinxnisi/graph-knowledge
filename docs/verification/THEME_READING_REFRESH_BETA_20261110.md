## 情報の移動先

| 情報 | 通常の表示／到達先 |
|---|---|
| テーマ名・問い・導入・画像 | 中央上部。文字付き「このテーマについて」から詳しい説明と収録内容・出典・商品・翻訳へ |
| assertion・関係の向き | 年表は短い見出し／主文・対応する対象と矢印、右は全文。図の線は同じ固定Recordを選ぶ |
| scope | 詳細本文下11pxの通常注記。170字を超える補足は下部の記録情報。年表には複製しない |
| 肯否・種別 | 種別は小さなアイコン付きラベル、否定・不確実は別の状態。肯定を認証バッジにしない |
| 全ての時間・精度・期間／発生幅／未分類 | 元の時間データと描画規則を保持。詳しい時間と意味は記録情報、共通の「線の見方」。子年表だけは実際の開閉を保つ |
| 日時のない6記録 | 図／年表の下の開いた一覧を基本試作。Bでは上部の小さい入口。全件が選択可能 |
| 支持／反証／背景・複数出典 | 共通出典部品。evidence IDで押した出典を開く |
| 引用・該当箇所・書誌・資料版 | 同じ出典の「引用と該当箇所を読む」。資料ごとの書誌と資料版を保持 |
| 原文言語・訳文・意味対応・内容版 | 記録情報・翻訳・補足。原文を更新せず表示用訳文を重ねる |
| Entity別名・同一性・投稿者・訂正 | 対象情報・翻訳、既存の投稿者／関連対象の整理、訂正リンク。人物の本文より先に管理項目を並べない |
| 保存・Capsule・編集／Undo・戻る | 既存操作を維持。閲覧用の短文表示と編集用の全文展開を別モードにする |
| 広告 | 既存枠は保持。書籍・カレンダーの広告リンクと科学的出典を分ける |

画像は[ESA/Webbの実画像](https://esawebb.org/images/webb-first-deep-field/)。NASA, ESA, CSA, and STScIのcreditをテーマ、TOPのカード、OGへ共用。[CC BY 4.0の条件](https://esawebb.org/copyright/)を確認し、credit・alt・焦点・寸法・確認日を保存。生成した実機写真や未検証の書影を使用しない。

表示manifestはサーバーの公開認可後に同じID・版・言語へ投影する。全カタログを静的クライアントJSへ入れない。元版が変わった場合、対応する編集情報を新しい版へ黙って継承しない。
