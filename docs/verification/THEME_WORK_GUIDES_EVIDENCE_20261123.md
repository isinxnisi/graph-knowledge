# Issue #80 βの画面証拠とガイド比較

対象はβ。Issue #79の元の比較ケース・受付・評価・画面証拠と、本番のテーマ・ガイド・定期実行は試験対象から外す。再比較の目的は、日英画面の欠測を解消した上で、作品の重要な不足に気づき、読者に届く変更を1回の起動で反映できるか確かめること。

## 発生箇所

- 黒澤の4受付はすべて受付時点で `target.locales: ["ja"]`。日本語のPCとスマートフォンを各5枚採取し、英語の採取は始まっていなかった。日本語で読み出せなかった2枚は `ja-1440-timeline-image.png` と `ja-390-timeline-image.png`。保存済みのPNG名がMCPの入力パターンを通らなかった。対象は順に K1A `484a3565-8354-44b0-bd08-00b38dc91fbf`、K1B `1b625cf1-083a-4d30-ae5e-353e150f6d45`、K2A `13eec925-3c46-4101-b8d4-f982eb5d9ad1`、K2B `f2b26d90-12f6-4684-88bb-66d9be65e2a1`。
- 黒澤の英語版提供条件を満たさなかった直接の理由は、4件共通の年表Recordの `assertion` 6件と、K2Aのテーマ固有 `title`／`description`。別の表示上の欠落として、共通の `timeLabel` 6件およびK2Aの `axisLabel` がある。日英の編集見出しやStoryが揃っても共通Recordの本文と時点ラベルは翻訳されない。
- K2Aのテーマ固有項目は `theme:8f4ac71621af8c586278a7161d03c36859d9d2ffc86ed9c9@2`、軸は `issue79-calendar`。共通Recordの末尾と時点IDは `8ff2920278e6c/time.t01`（隠し砦の公開）、`12dd9b231d137/time.t02`（映画学校）、`0f007838c8beb/time.t03`（スター・ウォーズ米国公開）、`3cabd6988c208/time.t04`（影武者撮影）、`304b396f6d623/time.t05`（影武者公開）、`52994c0a31835/time.t06`（アカデミー名誉賞）。いずれも記録版1。

## 対応と編集残件

- 採取・読取で同じ許可済みPNG名を使う。記録画像のある年表の拡大・復帰が観測できない場合は、その組み合わせを採取完了にしない。日英が必要な呼び出しは `requiredLocales: ["ja", "en"]` を指定する。ガイドが必須指定する言語も含め、供給できない言語があれば `PREVIEW_LOCALE_REQUIRED` と対象版・不足フィールドを返し、受付を作らない。従来の呼び出しでは受付の `target.locales` と `unavailableLocales` で範囲を確認する。受付の `complete` は選択された対象内での採取完了を表す。
- 画面証拠は現行の対象digest・Web build・ガイドの証拠要件版・実行権で照合する。MCPが返す前に実データと保存ハッシュを照合し、不一致は読取済みに記録しない。合格に必要な証拠は見直し実行で全部取得し、評価者が実画面を確認する。
- 出典の根拠欄を「根拠／Evidence」とし、明示された引用と要約を区別する。種類未記録の既存抜粋は「資料メモ／Source note」と表示する。英語画面で日本語にフォールバックした本文と掲載箇所は日本語と分かる表示にする。翻訳不足は編集残件として残る。
- 既存画像メタデータで挿絵と登録された素材は、記録詳細と拡大画面に「挿絵／Illustration」と公開クレジットがあれば表示する。1990年の授賞式再現画像は用途・表現・出典を個別に確認する。元の #79 黒澤比較原稿にはこの画像がスター・ウォーズ公開の行にもあり、受賞行との取り違えは作品の編集残件。実際の授賞式写真の使用やオマージュへの差し替えには、別途それぞれの利用条件と表現の確認が必要。
- 1979年『影武者』のRecord `…3cabd6988c208@1` の `ev.t04` は撮影再開の箇所だけを抜粋しており、ルーカスとコッポラの支援という主張まで直接には支えていない。登録済み出典の直前の支援・資金交渉の記述と、黒澤自身が不足資金を両名の働きで20世紀フォックスが補ったと述べた講演を確認した。撮影の時期と支援の内容をそれぞれ対応する根拠に結ぶのが修正候補。 [登録済みの伝記](https://akirakurosawa.info/biography-part-10/)・[黒澤明の京都賞記念講演](https://www.kyotoprize.org/wp-content/uploads/2019/07/1994_C.pdf)
- 黒澤の同条件の日英比較を追加するには、共通Record原本に影響しない翻訳・出典補正を用意し、同じ開始データで旧新両方を試す。#80の技術確認には別の非公開Webb案件を使う。元8案件や共通Recordへの補正書込みはしない。
