# テーマ詳細の解説一覧の配置修正（2026-11-11）

## 指摘と修正範囲

テーマ概要の「問いをたどる」が、番号付きリストと可変幅の枠付きボタンの組み合わせで、読む入口と汎用操作ボタンを混在させていた。KnowledgeReading.module.css の章リンクが存在しない --accent / --muted 変数を使い、汎用ボタンに優先する局所ルールも不足していた。前回の画面確認はこの外観を検出できていなかった。

既存の根拠付き解説への導線を「解説を読む」の見出しにまとめ、番号・本文・右矢印の三列を固定する。通常時は背景・枠・影を設けず、ホバーとキーボードのフォーカスを表す。読む行は文字の長さにかかわらず欄幅全体を操作できる。次の解説への操作にも汎用ボタンの枠が混ざらないようにする。出典の初期3件・明示展開／折り畳み、既存商品カードと表示、登録済みデータ、翻訳・戻りの状態保持は継続する。

今回は右ペインのこの指摘への修正であり、テーマ全体の視覚品質の承認を意味しない。本番の公開は別途承認。

- Windows Chromeの1500px／HTTPS βの390pxで、解説3行の同じ幅、境界線0、透明背景、横溢れなしを確認。PCは行幅386px、390pxは344px。
- 出典3→12→3、解説を開く→一覧へ戻る、戻った後の出典3件を確認。

## iPhone実機との表示差（同日の利用者報告）

利用者のiPhone Chromeは拡大設定「既定値」。写真では商品の説明の折り返しが多く、購入地域の標準selectが大きく、見出し下へ操作群が折り返している。利用者に設定変更を要求して解決する扱いにはしない。

Windows版Chromeで同じβ内容を読んだ再測定：

- 390px：カード322px、画像128px、商品名・紹介の欄158px、カード高さ約290px。

## 全体の差を商品欄の修正と混同しない（再報告）

利用者の写真では、紹介文の下段化と地域選択の外観変更は届いているが、テーマ全体の文字・密度の差は残っていた。キャッシュ問題とは扱わず、前回の商品欄の修正だけで全体の差を解消したように案内した範囲判断を訂正する。

再調査ではLinux WebKitの既存本体へ必要ライブラリを/tmpに展開し、OSへinstallせず起動を試した。共有ライブラリ不足は解消したが、ヘッドレスEGL displayの作成で停止し、iOSと同一描画の受入には使えなかった。依存ファイルは約64MBの隔離ディレクトリに限定。システムパッケージ・Docker・共有サービスの設定変更はしていない。

実機の値を推測で埋めないため、localhostとHTTPS βだけで ?displayCheck=1 を明示した時に限る計測表示を追加した。通常URLと本番では出さない。viewport／visualViewport／文字指定寸法／日本語1字の実表示幅とcanvas計測幅／text-size-adjust／userAgentをローカル画面へ表示し、明示クリックでコピーする。会員情報・入力内容を取得せず、外部送信・保存は行わない。100%比較は診断中だけのinline指定で、戻す・終了すると元の設定を復元する。

既定閲覧に影響しないことと補正復元の2テスト、eslint、型検査込みbuild成功。375×630で非表示→比較→補正前後を一括コピー→元へ戻す操作を確認。β build WU7g3iA4BYWF9qyYj1nbDへ配置。今回は根本修正完了ではなく、iPhone実機の診断値待ち。通常ページのCSS補正を断定で追加していない。


## 実機診断値に合わせた画面全体の配置（追加）

利用者がiPhoneのChrome・Safari・ChatGPT内ブラウザで計測した値を受領した。3環境ともCSS幅375px、screen 375×812、DPR 3、visualViewport.scale 1。実際に内容を表示できる高さは順に631／664／606px。text-size-adjustをautoから100%へ変えても、テーマ名23px・商品名14px・紹介文12pxの指定値、要素寸法、日本語1文字の実表示幅はすべて変わらなかった。この条件で文字の自動拡大を原因とする証拠はなく、一般閲覧の補正設定は追加しない。

一方、従来の主な検証は390×844px等で、実機の可視領域を大きく見積もっていた。また、同じ375px・同じ文章欄143pxでも、iPhoneの商品名は高さ63px（3行）、紹介文は幅281px・高さ60px（3行）。Windows Chromeではそれぞれ約43px／41px（2行）で、同じCSS寸法でも字体と折り返しの差があった。以降は375×606pxを最低の代表確認条件とし、幅だけのエミュレーションを実機と同一と扱わない。

### 今回の調整

- スマホの導入は、挿絵・問い・短い本文のプレビューとする。画像の表示高さ91→68px、本文の文字サイズは維持し、説明を2行までに抑える。全文は同じ「このテーマについて」から開く詳細の冒頭へ置く。データそのものは省略しない。PCは従来の全文表示を維持する。
- 「このテーマについて」はスマホで囲み付きボタンから控えめな文字リンクへ変更し、導入内の高さを整える。
- 閲覧用年表の人物・作品名や関係を示す補助行を、主文と関係図ボタンの横並びの内側から外へ出す。関係図ボタン分の幅を補助行から差し引かず、本文の折り返しを抑える。主文・日付・点と範囲の意味やデータ、編集・Capsule側の配置は変更しない。
- 商品欄は前工程の画像128px・本文幅281px等を維持。今回の全体調整と商品単体の完成評価を混同しない。
