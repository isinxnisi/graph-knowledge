# スマホの移動階層と共通ヘッダー（2026-10-24）

対象は実コミュニティと既存アカウント。会話デザイン、権限、API、保存形式は変更しない。

## 採用した構成

- 個人ナビゲーションを「コミュニティ」「アカウント」「活動・履歴」の3カテゴリに整理する。スマホでは上段に現在のカテゴリと切替メニュー、下段にはそのカテゴリの項目だけを表示する。分類名をスクロールレールへ混ぜない。
- カテゴリメニューでは別カテゴリの項目をグループ別に示し、目的の項目へ直接移動する。先頭画面を中継しない。項目変更は同じ共通枠の本文を切り替える。現在地は URL/hash に対応し、取得結果のタイミングでは決めない。
- 個別コミュニティと会話は、どの入口から到達しても「コミュニティ」カテゴリに属する。未参加でも「参加・運営」を選択中と表示しない。所属先の名前と、その下にあるスレッド・管理のタブで局所の現在地を示す。
- PC は従来のサイドナビを維持し、同じ3分類を表示する。Graphへサイドナビを追加しない。
- スマホヘッダーはブランド、明示的な「メニュー」、表示設定の3要素。探索への復帰・コミュニティ発見・本人の機能をメニュー内へ集める。頭文字だけの本人表示をヘッダーから外し、メニュー内に表示名とログイン状態を記載する。招待バッジは閉じたメニューにも残す。
- 認証確認中のメニューでは公開の移動先を使え、本人機能を未ログインと断定しない。未確認・失敗・未ログインの既存の区別を保つ。
- コミュニティ見出しは「名前＋右側の補助メニュー」「説明」「公開状態＋参加操作」に分ける。3点ボタンを単独行へ落とさない。ポップアップは本文を押し下げず、従来の Escape／外側操作／確認ダイアログを使う。

## 色と可読性

ライトの個人画面とヘッダーに限り、補助文字を `#5c6f83` → `#506478`、境界を `#dfe4e5` → `#cdd6da` とする。選択面も少し明確にする。本文のサイズ・書体は維持する。全画面の一律拡大や scale は使わない。

ダークでは既存のテーマ変数を使う。コミュニティの入力面・主要操作・警告の固定ライト色はテーマ変数へ合わせ、明暗で役割を揃える。Graph の配色定義は変更しない。

## 保持する契約

共通認証ストア、内部 Link/hash 遷移、入力中の移動ガード、招待件数ストア、投稿地点の読取、通報の冪等性、再認可と失効時の本文保護を再利用する。新たなデータ保存や API/migration は追加しない。C2/AI、3275の試作、本番は対象外。
