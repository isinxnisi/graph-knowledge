# 探索UIの表示言語

2026-10-13。公開β工程15の採用契約。日英の探索入口・条件・Graph・関係概要・Entity／Claim／Citation／Source詳細を対象にする。会員・共有・保存／閲覧画面全体の英語対応は工程16。

## 言語の責務

共通ヘッダの「設定 → 表示言語（探索画面）」で日本語／Englishを選ぶ。初回は日本語。同一originのブラウザ設定 `graph-knowledge.ui-locale.v1` へ保存し、再訪・別タブで引き継ぐ。ログインや会員APIは使用しない。en-US等はen、未対応／破損値はjaへ解決する。保存不能でも当該画面には反映し、その状態を設定内へ表示する。

React contextは表示localeだけを持つ。純粋なpresentation／日付関数にはlocaleを明示的に渡し、省略時は既存のjaを維持する。辞書は `lib/i18n` に置き、英語のキー・関数形を日本語と型照合する。サーバーの意味検証とAPI契約へlocaleを流し込まない。html.langとブラウザ題名も表示言語に追随する。

Entity名・説明・aliases、Source名・著者・原語表記、Citation locator・note・資料の限定は登録原文をそのまま表示する。英語UIへ切り替えても、資料や対象の名称が英訳される機能ではない。日付は日本語年月日／英語ISO形式で同じ精度を保持する。部分日付を補完せず、Event自身の開催期間とClaimの期間不明を区別する。

## 探索を変えない境界

言語を変更しても以下を変更／再取得しない。

- 検索語・検索kind・検索候補、起点・選択、適用条件と未適用draft。
- predicate／三つのtyped限定のID・null・空集合・条件キー・cursor・受理済みページ。
- 探索世代・開閉意図・休止枝・直前一件のsnapshot、進行中通信。
- Claim UUID・比較キー・SPO単位のDisplayRelation ID／構成、知識データの肯否・scope・根拠。
- Cytoscapeのインスタンス、Node座標・pan／zoom。

Graphは表示ラベルとbadgeのdataだけ更新する。新しいNodeや探索世代がなければレイアウトやfitをやり直さない。英語のラベル長によって見た目の混雑が変わる可能性は残るが、言語切替を理由に利用者の配置を動かさない。

既存GraphState／snapshotの通知文は今回変更しない。既知のUI通知・取得エラーだけを表示時に辞書へ解決する小さいadapterを使う。原資料の自由文には適用しない。未知のサーバー通知は原文へfallbackする。将来通知種別を構造化する場合も、言語を探索状態の同一性へ含めない。

条件editor・概要・詳細をlocaleで再mountしない。別タブで言語が変わっても、入力・draft・詳細の取得結果を保つ。条件の明示適用・検索候補の選択等、既存操作による取得だけが新しい通信を起こす。

## 段階的な対応範囲

今回、会員／共有・ブラウザ保存・直接閲覧の画面全体は日本語のまま。該当領域はlang=jaを明示し、設定にも工程16の対応範囲を案内する。共通のClaimカードやGraph等はlocaleを利用する。未対応のコンテンツや全体UIまで翻訳済みとは扱わない。

多言語のEntity名称モデル、検索の言語別条件、URL／共有リンクへのlocale固定、会員の言語同期、翻訳AI、地域別日付・時刻の推測は追加しない。今回はDB・API・凍結dataset・fixture・依存package・GraphState／snapshotを変更しない。
