# Discovery Search 初期実装

2026-10-16。[Issue #4](https://github.com/isinxnisi/graph-knowledge/issues/4)の実装単位。[M3の体験目標・仮案・未決事項](M3_DISCOVERY_EXPERIENCE_CONTEXT.md)を置き換える最終仕様ではない。

## 利用者の操作

- Homeの紹介直下に「名前やテーマから探す」。既存検索ペインの「一覧・条件から探す」も、入力なしの一回の操作で検索ダイアログを開く。空欄の検索実行も同じ入口へ接続する。強い検索ボタンを二つ並べない。
- 名前・別名を入力すると250ms後に候補を更新する。変換中は取得を待ち、入力／種別変更とunmountで前の通信を取消す。遅い応答で候補やエラーを上書きしない。既存の明示検索も維持する。
- インライン候補は最大5件。名前・種別・短い説明・別名で見分け、選ぶと既存Graphへ進む。下矢印で最初の候補へ移動でき、通常のTab／Enterでも選べる。「すべての結果を見る」で入力と種別を引き継ぐ。
- PCは最大1000pxの広いダイアログ。スマホは画面に近い幅を使い、起点の選択肢を横スクロールの一列へまとめて一覧の縦幅を確保する。見出しと閉じる操作は固定し、本文は一つのスクロール領域にする。
- 名前は任意。人物・作品・組織・出来事と名前を組み合わせ、結果を見ながら変更できる。20件ごとの前後ページを表示し、名前の完全一致を優先、その後は名前・UUIDの安定順とする。順位を人気や信頼性と見せない。
- 「つながりから探す」は、既存の編集的な公開起点（PLUTO、長崎尚志、研究所、会議）を現在KGで確認して表示。選ぶとその対象と、公開Claimを介した直接の相手を候補にする。名前・種別は維持する。漫画全般・研究分野全般の分類結果、複数段の探索プリセットではない。否定を含む登録関係もあり、現実の関係成立をこの集合から断定しない。
- 一致なしでは条件のクリアと実在する起点を残す。公開データがない状況や通信失敗は、架空の候補で埋めず再試行を提供する。
- 閉じる・Escape・ブラウザBackで以前のGraphを維持して戻る。Forwardでは検索を再表示する。検索の開閉をURLそのものの形式へ固定せず、native Historyの一時的なstateを一件だけ使う。検索内の言語変更は入力・条件・取得済み結果を保持する。

## 状態と取得

既存 `/api/entities` のキーワード必須・10件／最大20件の契約は変更しない。インライン候補はこのAPIを使用する。空欄とページングは新しいread-only `/api/discovery/entities` に分ける。`q`・`kind`・`around`・`after` のみを許可し、重複・未知条件・100文字を超える入力・不正cursorを拒否する。

新APIはpublished Claimに接続したKG Entityだけを返し、会員PG・Capsuleを参照しない。21件取得で続きを判定し、一度に20件だけ返す。queryはパラメータ化し、検索語をCypherへ埋め込まない。cursorは検索語・種別・周辺起点・dataset・revision・最後の順位／名前／UUIDに束縛する。条件を変えたcursorは400、公開KG更新時は409として検索のやり直しを促す。Graph復元用のcursorや探索URLへ流用しない。

ダイアログの検索も250msのdebounceとAbortControllerを使う。直近24条件だけを30秒間メモリにキャッシュし、再試行では破棄する。条件変更中は古い候補を選べない。GA4へ検索本文やcursorを送らず、既存の内容なし操作イベントの境界を保つ。

Graphへは既存の起点選択処理で進む。検索のkindや周辺起点は候補を探す条件であり、Graphの関係条件を暗黙に変更しない。Homeからの開始は既存routeのpush、既存Graphからは既存の起点切替・直前復帰を使う。閉じるだけでは枝・位置・Zoom・選択を変えない。開く前に現在の探索URLを確定し、取得途中など確定不能なら既存の警告を残す。

## 後続へ維持する要求

分類タグの意味・複数選択AND/OR、見たい関係や方向／多段の探索プリセット、検索条件からGraph条件の引継ぎ、公開Capsuleの発見、Graph個別関係閉鎖は未実装の重要なM3目標として維持する。現在の周辺起点・kind・名前一致で代用した扱いにしない。

画像は現行Entity APIに取得元・権利・同定情報がないため追加しない。結果行は小さな種別アイコン＋本文を使い、将来のサムネイルも識別補助の大きさに限る。架空の画像、利用不可のCapsuleタブ、未接続のタグ／プリセットは設けない。

実画面・日常確認先・VPSの状態は[公開β進捗](../PUBLIC_BETA_PROGRESS.md)に記録する。この初期版だけでM3全体を完了としない。
