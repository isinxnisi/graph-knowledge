# 投稿対象の識別と外部資料リンク

2026-11-06 R1h。既存デザインに分類・短い説明・関係端点を添え、名前だけでは選べない対象を比較できるようにする。資料リンクは共通UIとURL検査を通し、題名と実際の遷移先を区別する。

## 対象を選ぶ

- Common／旧KGの検索結果の説明を利用する。検索順位は維持し、同じIDの旧KG結果が現在の共通知識を上書きしない。
- 常時は分類と説明、関係には端点・具体的な関係語・否定／不確実を短く表示。必要時の「候補の詳細」で別名・資料名・ID・版と全文を読む。人物等では詳細を開いたときだけ公開中の関連知識を最大3件取得し、説明がない同名候補も比較する。読取は既存の公開近傍APIで、一覧表示だけでは追加取得しない。新しい行やモーダルを上部に増やさない。
- 選択後・草稿再訪でもサーバーが固定した対象の説明を表示する。説明の一致だけで同一人物と判断／統合しない。投稿の権限・対象・版は従来どおり認証付きtargets処理で再確認する。
- Commonだけの操作に旧KG候補を混ぜず、検索失敗を空の成功や一部成功として表示しない。件数・検索範囲は従来の先頭20件の明示を維持する。

## 外部へ開く

- http／httpsのみ。資格情報、制御文字／逆向き制御等を含むURL、ローカル／私有IP、ローカル名は開くリンクにしない。資格情報を含むURLそのものをラベルにも表示しない。
- 通常のHTTPS資料はタイトルと実際のhostを併記し、直接開く。HTML化しない。題名とhostは双方向文字の影響を分離し、hostを左から右のASCII表記で示す。
- HTTP、国際化ドメイン、公開IP、非標準portはその場の小さい確認を開き、実hostを確認してから別タブへ開く。全リンクへの一律モーダルは追加しない。
- 全資料リンクにnoopener／noreferrer／no-referrerを付ける。通常KG、共通知識、年表、Capsule、確認画面・収集一覧の8か所で共用する。外部への事前アクセスや有料URL評価サービスは使わない。
- host表示は安全認定ではない。遷移後のredirect、一般ドメイン上のフィッシングを完全に判定する機能ではない。
- 自動取得は既存publicSourceDocumentを継続し、公開IP判定・DNS先固定・各redirectの再検査・容量／時間／形式制限を通す。Cookieや秘密値を資料先へ渡さない。ブラウザ向けの許可と取得許可を同一視しない。

## 次の境界

R1は未完了。配置別の公開読取／会員投稿／運営／Worker資格を、現在のβ専用literalから明示capabilityへ整理する。生成草稿の公開文脈はR1gで接続済みだが、訳文の意味一致確認は現状、原文と訳文・field/kindだけを送っているため、同じ公開文脈の固定と受理時検査へ接続する必要がある。AIの自由文が権限・取得先・actor・予算を変えない境界の横断検証も次に残す。

R2の全件自動巡回・整理、R3の定期配送・収集、R4の探索／入力／多言語接続、R5全体一巡は初版範囲として維持する。本番VPS切替とLinux脆弱性対応は別の正式反映工程。
