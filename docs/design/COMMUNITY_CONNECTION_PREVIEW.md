# コミュニティと本線UIの接続確認版

2026-10-21。コミュニティの基礎権限・公開範囲・所有モデルは変更せず、画面接続と密度を評価する。

## 採用した構成

本線UIをコピーして隔離Nextアプリを生成する。共有の本番コードへ試作フラグ・架空ユーザー・routeを追加しない。3275 / graph-comだけが新確認版。3200 / betaは既存検証済みbuildのまま。

| 場所 | 再利用と追加 |
| --- | --- |
| Home | ExplorationPage・DiscoveryHome・SiteHeader・既存検索/詳細ペインをそのまま利用。共通ヘッダーにコミュニティ入口を追加。狭幅は既存の検索/Home/詳細切替を維持 |
| Graph | Explorer・GraphCanvas・関係編集・既存URL/Workspace復元を再利用。コミュニティ掲載からの到達時だけ掲載一覧への戻りを追加。常設サイドバーなし |
| アカウント | MemberCapsules・Capsule Reader・投稿・設定を再利用。既存PCメニューに「参加・運営・招待」を追加。スマホは上部で折り返す。会員データ取得だけ架空adapterへ置換 |
| コミュニティ | 既存試作のHome/Capsule/スレッド/メンバー/管理を同一originのframe内で継続利用。独立したコミュニティ内タブと、アカウント全体のメニューを分離 |

iframeは今回の既存試作再利用の境界。本線への正式導入時には認証/権限を伴う通常コンポーネントへ移す。簡易トップ・別Graphで代用しない。

## 入口と戻り

- Homeの共通ヘッダー → 一覧 → コミュニティ → 掲載Capsuleの公開KG参照を本線Explorerで開く → 元のCapsuleタブ・スクロールへ。
- Graph → 既存アカウントメニュー → 参加/運営 → 閲覧/管理 → 元アカウント → 既存「探索へ戻る」。GraphのURL生成・完全経路再検証・ノード配置・開閉をそのまま使用。
- アカウントの自分のCapsule一覧/Readerに「コミュニティの掲載先」を追加。選択Capsuleのqueryとメニューhashを保持して戻る。
- 明示戻りは入口URLを記録する。ブラウザ戻る/進むはブラウザ履歴。直接URLで初めて開いたページに存在しない「元の画面」は出さない。
- Graphの既存URLはpanを含まないため、確認版だけURL・公開revision・ロールに結び付くpanをsessionStorageに最大10件保持。既存再検証が成功したときのみ適用。保存形式は変更しない。スクロールでGraph snapshot全体を履歴へ複写する処理は追加しない。
- アカウント変更で入口・pan等を破棄。コミュニティは復帰時にも現在のロールで閲覧判定し、非表示時のDOMを取り除く。実際のサーバー側失効・セッション処理は未接続。

## 密度の調整

コミュニティ名43→28px（スマホ25px）、見出し26→22px、一覧タイトル20→18px、行の上下余白25→16px。大きな装飾orbitを省き、横幅1080pxで情報を左、Graphなどの主要操作を右へ。説明は13px・補助は12px前後を維持。一律scaleを使わない。iframeの高さは内容要素から計測し、前画面の高さによる余白が残らないようにする。

## 模擬の範囲と未接続

会員・Capsule本文・コミュニティ・招待・掲載/管理操作は架空。掲載参照c1/c3は公開PLUTO、c2は公開Princetonへ接続するデモ対応であり、実Capsuleの所有・公開版をKGへ統合したものではない。貢献や真偽を表さない。

Graph自体は実Explorerと公開KGの読み取り。ローカル保存・共有URLの既存機構を使用する。会員保存・招待配送・限定共有リンク発行・実コメント投稿・AI送信は未接続。プロフィール編集や削除等の主な実書込操作は無効化し、画面にも未接続を表示。fixtureを本番認証の代わりに使わない。

次工程は本確認版のサイズ感・導線を人間評価した後、独立コミュニティデータモデルと実認証による権限再検証を実装する。既存会員APIやCapsule共有権をコミュニティ参加へ読み替えることはしない。
