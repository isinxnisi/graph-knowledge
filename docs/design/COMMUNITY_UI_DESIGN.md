# コミュニティ UI デザイン体系（2026-10-24）

対象は実コミュニティ C1a/C1b/C3-min。権限・公開範囲・参加世代・保存形式は変更しない。C2 と AI は対象外。

## 採用する方向

「関心のある場所 → 話題 → 発言 → 会話を続ける」を表に出す。管理・撤回・通報は、その対象に属する補助操作としてまとめる。ライトな本線の書体・色を保ち、小さな場所のシンボル、投稿者の頭文字、青緑の入力面を共通の目印とする。人数・活動状況を創作しない。

参照した公開資料（ログイン後の画面を閲覧したものではない）：

- [Discourse Horizon](https://meta.discourse.org/t/horizon-theme/360486?tl=en)：公式紹介と掲載された会話画像を確認。話題を読みやすい単位にまとめ、アバター・投稿者・日時・本文を一体にする考え方を採用。テーマ全体や大きなサイドバーは移植しない。
- [GitHub Discussions](https://docs.github.com/en/discussions/managing-discussions-for-your-community/managing-categories-for-discussions)：カテゴリの名前・記号・説明の組合せを参考に、場所の識別記号と所属先表示へ適用。公式ページの画像で確認できたのはリポジトリのナビゲーション部分であり、会話画面全体を確認したとは扱わない。カテゴリ機能は追加しない。
- [Discord Forum Channels](https://support.discord.com/hc/en-us/articles/6208479917079-Forum-Channels-FAQ)：公開 FAQ の、会話ごとにまとまった一覧と投稿作成の区別を採用。チャット・リアルタイム・リアクションは追加しない。
- YouTube の「登録済み」は利用者が示した操作意図を参考にする。参加中の状態と関連操作を同じコントロールにまとめ、退出を日常の主導線から分ける。YouTube のログイン後画面を今回確認したわけではない。

## 共通規則

|用途|見出し・幅|主操作と情報|
|---|---|---|
|場所一覧・参加一覧|ページ名＋短い説明、本文幅を活用|場所の記号／名前／説明を左、訪問を右|
|個別コミュニティ|場所の名前・公開範囲・参加状態、下に既存タブ|話題一覧を先に表示。作成は明示的なボタン|
|会話|スレッド名を H1、コミュニティ名は所属先、最大 800px|頭文字・投稿者・日時・本文。投稿操作は右上のメニュー|
|作成・返信|作成は専用の入力面、返信は会話の末尾|入力と送信を同じ淡い面にまとめる。作成と返信の確定ラベルを区別|
|自分の投稿|所属先・話題名・抜粋・日時|該当発言で読むことを主操作、撤回は確認付き補助操作|
|招待・参加履歴|同じ見出しと一覧規則|実際の状態と期限、承諾等の次の操作。非公開の名前は認可済みのものだけ|
|管理・履歴|設定名・現在値・説明、読みやすいフォーム幅|メンバーの役割と操作を一組にする。履歴は実監査情報だけ|

アイコンは既存 Icon を再利用し、基本 17px。場所のシンボルは許可済みタイトルから色を決めるだけで、分類や評判を表さない。人物は許可された表示名の頭文字のみ。非表示・撤回済みの投稿に元の名前を戻さない。

PC は情報左・操作右。スマホでは主操作を次の行へ回せるが、見出し・本文を極小化しない。個人ナビゲーションは共通コンポーネントを維持し、狭幅ではグループ名付きのコンパクトな横スクロールにする。選択項目が見える位置へ追随する。Graph にはこのメニューを常設しない。

補助メニューは本文を押し下げず、クリック／タップ・キーボードで開く。外側クリックと Escape で閉じる。確認ダイアログはメニューとは別に document.body へ配置し、既存の再認可時の閉鎖・入力保持・フォーカス復帰を維持する。

## 会話地点への読取契約

- `GET /api/communities/my-posts` に createdAt と readable を追加。現在その会話を閲覧できる場合だけ threadId/threadTitle/communityTitle を返す。本人に従来許可されていた自分の本文と撤回は、会話の閲覧許可とは別。
- `GET /api/communities/threads/:id?post=:postId` はコミュニティ・会話の認可後に、その会話内で投稿位置を解決する。他の会話の投稿や存在しない投稿は 404。
- 全件取得せず、最大半ページ＋1件の先行投稿から既存 cursor の開始位置を作り、前後の会話を最大 limit 件返す。通常の次ページ cursor、利用者・policy・期限の検証は従来どおり。
- 投稿履歴からの戻り先・スクロール位置はタブ内メモリだけで保持。非公開本文・草稿を History/localStorage に保存しない。
- スレッド一覧の件数・更新時刻は、閲覧可能な各スレッドの実投稿から取得。外部へ名簿や非公開スレッドの件数を追加公開しない。

## 入力・復帰

作成の取消は入力があれば確認し、未送信のまま一覧へ戻せる。作成成功時はサーバーの返したスレッド ID へ移動。返信成功時は返された投稿 ID で位置を解決する。失敗時は入力を残す。フォーカス・タブ復帰・通常再取得では既存の入力保持を維持し、別 User・権限変更時の破棄は既存のセッション処理を使用する。

## 境界

既存 User/Capsule/コミュニティ/投稿を保全する。実 beta で利用者の投稿の変更・撤回・招待送信による試験は行わず、書込み試験は隔離 DB と実 OIDC 認証で行う。公開判定は beta 評価後に別途行う。
