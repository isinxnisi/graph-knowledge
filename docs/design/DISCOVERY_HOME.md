# Discovery Home 初期実装

2026-10-16。M3の最初の実装単位。[体験目標・仮案・未決事項](M3_DISCOVERY_EXPERIENCE_CONTEXT.md)を置き換える確定仕様ではない。M3全体の完成と実画面に対する本人の評価を区別する。

## 利用者の操作

- 日英のトップ `/`・`/en` では中央にDiscovery Homeを表示。スマホもHomeから始まり、上部の検索タブへ直行できる。Graphへの直接URL・保存途中の再開はHomeを経由させない。
- PLUTOの紹介カード全体からワンタップでGraphを開始。紹介図の人物・役割は現在の公開KGの関係から作る。画像や架空の関係、人気・活動実績を生成しない。
- テーマ別の入口から、長崎尚志、ニールス・ボーア研究所、第5回ソルヴェイ物理会議へ進める。これは編集的に選んだ実在の起点であり、分類タグによる検索結果や探索プリセットではない。
- 最近加わった対象からGraphへ、関係の記録から両端のGraphまたは資料・記録の閲覧へ進む。資料リンクは既存の閲覧モーダルを使う。
- Home下部の名前検索リンクは既存検索ペインの入力へ移動。大きな検索ボタンを二つ並べず、PCの検索フォームとスマホの検索タブを維持する。
- 全ページのPlunodeロゴ・タイトルは日英のHomeへ戻る通常リンク。Graphから離れる前に既存URL処理で枝・条件・座標・Zoomを確定する。未取得・上限等で確定できなければ既存の警告で移動を止め、状態を黙って捨てない。

## データと履歴

`lib/server/discovery-home.ts` が公開KGをread-onlyで取得し、Homeの初期HTMLへ渡す。既存の固定例はUUID選定に再利用し、実際に存在し公開関係があるものだけ掲載。紹介図・新着の役割は既存の関係presentationを使う。

新着対象は公開Claimに接続したEntity、新着関係はpublished Claimに限定し各4件。`createdAt` の降順、同時刻はUUID順で安定表示する。日付はKGのシステム記録日であり、関係の成立日・資料の発行日・VPSへのrelease適用日時ではない。同日の表示を投入順と受け取らないよう注記する。件数は現在の公開Claimとその両端の対象を数え、会員PG・非公開Capsuleは参照しない。

HomeとGraphの開始を通常のページ遷移として履歴へ残す。Homeの検索結果・開始例も `/explore/{UUID}` へ接続し、Homeの履歴項目をGraph状態で上書きしない。探索操作ごとのURL更新は従来のreplaceStateを維持し、履歴を増やさない。ロゴHome→Backの復元は既存URL codecと現在KGからの再取得を利用する。新しい保存形式やGraph stateの第二の正本は作らない。

## 維持する境界・後続

2026-10-16の追加指定により、演出はTOP中央の見出し・PLUTO・テーマ・新着・検索の各まとまりに限定する。420msのフェード＋12pxの浮き上がりを80msずつずらし、全体は740ms以内。Graphカード全体へのフェードは取り下げ、既存のNode追加・スマホのペイン切替の効果を維持する。リンクのhover／keyboard focusは控えめな境界・背景・影の移行で押せることを示す。CSS transformで導入だけを動かし、レイアウト寸法・Graph座標・操作・取得・履歴を変更／待機させない。OSのreduced-motionでは導入と移行を無効化し、設定途中の変更にも即時追従する。

TOPの本文はDiscovery Homeへ一本化する。サービスの内容、無料・登録不要の案内、実在する起点と新着の内部リンクはHomeのSSR本文へ含め、下段のPublicDiscoveryによる紹介・開始例は生成しない。CSSで隠す方法は採らない。PublicDiscoveryはEntityページ専用とし、その関係・出典・原文・日英SEOを維持する。言語の通常リンクは共通フッターへ置き、JavaScriptなしでも対応する公開URLへ移動できる。Graph表示中の通常クリックではURLを確定して条件・枝・配置を言語間でも保つ。

Featuredの人物名・制作役割はHTMLの一覧へ移し、線の座標へ文字を重ねない。図は作品から複数の対象へ広がる装飾として控えめな曲線と点で描き、意味は同じ取得済み関係の人物名・roleを読むcaptionで伝える。役割は既存presentationの具体語優先・肯否表記を再利用し、未知の役割を補完しない。captionは通常のレイアウトで折り返し、高さ固定・ellipsis・切抜きに頼らず日英の文量へ追従する。

会員認証・保存・共有権限、Graphの開閉・条件・URL codec、M1支援、M2の日英SSR・検索境界・OGP、広告origin分離・同意・GA4送信項目を維持する。Homeの探索リンクは既存の操作名 `explore_start` だけを通知し、名前・本文・URL状態をイベントへ送らない。

Rich Discovery Searchの条件入力・インライン候補・空欄入口、分類属性、探索プリセットとGraph条件の引継ぎ、個別関係の閉鎖、公開Capsuleの発見は後続。今回のテーマ入口をそれらの完成形と扱わない。公開Capsule等の実データがない枠や未接続ボタンを設けない。新着の同日内の多様性・紹介の更新方法・Homeの情報量は実画面の評価から改善する。

日英×PC1440／スマホ390・320pxでHome→PLUTO→展開・座標／Zoom変更→ロゴHome→Back→再読込を確認。テーマ・新着対象・資料モーダル・検索からの開始とBack、JSなし英語入口も確認する。物理スマホとスクリーンリーダー音声の本人確認はブラウザのタッチエミュレーションと分ける。
