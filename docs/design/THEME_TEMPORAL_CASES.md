# Issue #75：仮想データによる時間表現のケース集

2026-11-01。実テーマの限定された組合せだけでは、時間モデルと表示方式の不足を確認しづらいという指摘への対応。独立確認版の `/themes/patterns` でケースを切り替え、実装中の共通入力検証・年表描画をそのまま使う。

## 評価を混同しない

- **入力**：通常パッケージのschemaに通るか。拒否されるべき不正値は拒否する。
- **意味**：入力できた文字や数値が、その時間的意味を保って使われているか。「前期」というlabelを保存できても、範囲を扱えたとは判定しない。
- **表示**：元の範囲・精度を保ちながら読み取れるか。入力可能を、見やすさの受入済みと扱わない。

ケースは「描画で確認」「仕様の不足」「入力を拒否」に区分する。仕様不足でも現行schemaが受理するケースには現行の図を示す。受理しないケースは原本と検証結果だけを示し、便宜的な日付へ置き換えた図を作らない。時刻や前期後期などの不足を、ケース集の追加だけで解決したとはしない。年月日の表示単位による点・幅の切替は、後続の描画更新で実装した。

## 今回の検証空間

61ケース。時間表現全般の完全網羅ではなく、次の有限の観点を明示して覆う。

| 観点 | 組合せ |
| --- | --- |
| 期間同士 | 前・後、端で接する2方向、途中で重なる2方向、同じ開始2方向、包含2方向、同じ終了2方向、完全一致の13通り |
| 記録精度 | 年・月・日、同じ年での混在、月と年の逆転して見える端点、同日の別の意味・複数記録、閏日・年跨ぎ |
| 発生候補幅 | 比較対象なし、中に出来事あり、境界と同日、候補幅同士の重複、表示対象を隠した場合 |
| 期間境界 | 途中の出来事なし、開始だけ不確か、終了だけ不確か、両端が離れる、両端候補の交差、精度の異なる境界 |
| 所属・文脈 | 同時期だが所属未登録、明示の所属、時期不明、周期、定性軸、明示した子軸 |
| 表示単位・接続 | 年・月・日切替、1991年の時点と年内の候補幅、同月の発生幅と実期間、同日開始と複数の点、年をまたぐ候補幅 |
| 密集 | 同じ時期の12期間。全件選択・レーン・年表内スクロール |
| 仕様不足 | 時・分・timezone・zone不明、未定義の前期・labelだけの前期・親時代の前期、離れた複数候補、表示除外 |
| 不正入力 | 非実在日、逆転、終了欠落、不正な開始・終了候補、発生幅への期間境界、時点への期間終端 |

13関係のケースは、順序・接触・重なりの観点のチェックであり、意味上の所属・因果を表す辞書ではない。境界の粗さや同日内の不明な時刻も保存された精度のまま扱う。

## 操作とデータ保護

ケース切替・線の選択・行展開だけではDBへ書かない。原本JSONと期待する振る舞いを確認できる。描画可能なケースだけ、選択した記録を既存 `/api/themes` の通常importへ通し、そこから関係図・Capsule・共有へ進める。保存時は新しいIDを使い、既存テーマやfixtureの固定IDを上書きしない。検証のために会員・KG・β・本番へデータを投入しない。

全データは仮想であることをタイトル・本文・対象・根拠欄に示す。根拠欄は実資料ではなくケース定義のURLである。`retrievedAt` は必須形式を満たす固定試験値で、外部資料を取得した実測日時ではない。
