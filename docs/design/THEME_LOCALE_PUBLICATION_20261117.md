# テーマの言語別正規ページを情報追加中も維持する

2026-11-17、実装前の選定。現行の正規ページは最新Theme構成だけを英訳充足判定し、追加Recordの訳がないと公開済み英語URLまで404になる。Webbの既存補完後は構成27の日英・対照英語とも実GET200、本文・言語・canonical・index許可・サイトマップ掲載を確認済み。既存11訳文や品質本文は書き換えない。

## 選定

既存の永続したTheme公開版・固定参照版・訳文履歴を再利用し、正規ページ用の言語別提供版を一つのread transactionで解決する。新しい本文cacheや別の承認・Worker・DB二重管理を設けない。現在版が言語充足なら即時に現在版を提供する。未充足の場合だけ、以前から提供可能だった、現在版まで安全な情報追加だけが続く直近の言語版を使う。旧版が当時すでに翻訳充足だったことは、必要訳文の初回公開時刻と後続Themeの公開時刻で照合する。初めての未翻訳テーマに過去の空版や、あとから一部だけ訳した版を公開しない。

## 停止と版の一貫性

最初に現在のTheme全体の公開認可を確認し、候補版でも現在の公開状態・依存資料・訳文を再検査する。削除・差替え・既存内容の訂正・参照版変更・非公開化は追加扱いにしない。中間版に訂正や削除があれば、その前へさかのぼらない。古い版の参照原本に新しい訂正版がある場合も、翻訳待ちを口実に過去を戻さない。現在の非公開訳文や新しいTheme項目の訳文撤回を、旧項目の訳文で迂回しない。

本文・Graph・年表・見出し・metadata・OGP・sitemap・hreflangは同じ提供版を使う。英語提供版が日本語最新より遅れているときは、その旨と構成版を表示し、情報を黙って消さない。`krev` 指定とCapsule／共有断面は明示された版を維持し、自動的に過去版を選び直さない。一般探索・運営read_themeも最新／指定版の契約を維持する。

## 完了確認

対象Themeと言語だけのGET検査を実装し、HTTP応答だけでなく可視本文・題名・lang・canonical・robots/meta／HTTP header・サイトマップ・alternateを確認する。DNS／timeout／HTTP／本文／noindex／sitemapの失敗を区別する。運営技術ガイドの登録後手順から利用できる読取操作とし、原本の公開処理やAI審査と混ぜない。全ノード巡回や追加LLM呼出しを行わない。GoogleのIndex登録は推測しない。

## 検証予定

隔離データで、英語公開→日本語日時Record追加→訳文準備→英訳反映の遷移を通す。初回未翻訳・翻訳済み・訂正／削除／edit-revert・訳文撤回・資料撤回・非公開・不存在・日英差異・固定版を検証する。βと正式で実GET／描画を確認し、データ補完・コード・試験・配置・実URLを分けて報告する。
