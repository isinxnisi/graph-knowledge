# 公開βの共通ヘッダとUI基礎

2026-10-12。公開β計画step8の採用範囲。[公開プラン](PUBLIC_BETA_AND_PRODUCT_PLAN.md)と[進捗](../PUBLIC_BETA_PROGRESS.md)を併読する。

## 今回の境界

探索・会員Capsule・限定共有に同じ `SiteHeader` を使う。サービス名、datasetの表示、画面間の入口、既存のテーマ切替を共通化する。ヘッダからprivateデータやsessionを取得しない。認証・所有者判断は既存の会員画面／APIに残す。

- 探索のヘッダに「アカウント ↗」を置き、既存 `/member` を別タブで開く。アカウント／共有画面からの探索も別タブ。探索途中や未保存の入力をナビゲーションだけで捨てない。
- アカウント画面はヘッダに現在地を示す。ログイン可否・本人確認・保存の状態は本文で確認する。未設定時は既存の利用不可表示を維持し、稼働していないGoogle登録を表示しない。
- datasetの識別は全画面で維持。共有／会員のh1は各画面の題名、探索のh1はサービス名とし、一画面にh1を重ねない。
- 全datasetへ継承されていたブラウザ題名の「架空のデモデータ」は外し、共通題名をサービス名とする。実際のdatasetの識別はヘッダが担う。
- ライト／ブラウンダーク／ブルーダークを維持。テーマは見た目だけを変更し、探索条件・選択・取得・座標を変えない。今回、会員設定や永続化には接続しない。
- 新しい文言は `lib/i18n/site.ts` に置く。locale解決境界を持たせるが、この工程で全画面を英訳しない。

## 見た目の責務

`app/theme.css` の既存配色を維持し、基本文字（14px・行高1.65）、control角丸6px、panel角丸10px、panel余白16pxを共通値にする。`app/ui.css` はbody・controlの字体、link、focusの基礎だけ。ヘッダと各画面の配置・状態はCSS Modulesへ残す。

探索は3ペインと中央カード単独スクロール、Graphの高さ調整、隣接一覧を維持する。左のブラウザ保存操作は間隔を揃えて縦に並べる。会員／共有は本文見出しと説明のまとまりを区切り、同じ背景・文字・control・cardの基準を使う。追加のUIライブラリは使わない。

意味を持つGraphの色・形・破線、Relation label、Claimの比較・根拠、dataset、API、DBは変更しない。ヘッダの追加は会員機能の公開有効化ではない。

実ブラウザでは探索→別タブのアカウント→元Graph、三テーマ、共有の利用不可表示、390px幅を確認する。テーマ／入口操作後のNode座標・Edge・pan/zoom一致とneighbors再取得なしを回帰条件にする。既存の条件／概要／根拠／起点切替と中央スクロールの代表経路、会員／共有の既存認可・保存経路も検証する。実施結果は[進捗](../PUBLIC_BETA_PROGRESS.md)へ記録する。
