# 公開探索の多言語表示を揃える

2026-11-09。UIの言語、登録された原文、登録済みの別表記、確認済み訳文を区別する。

## 今回の対象

TOPの人物紹介・他の対象・新着、開始例、対象検索、通常Graphのラベル／起点／選択表示、詳細、関係一覧、接点／経路一覧、公開対象ページを、同じ名前の表示関数へ接続する。原名やIDを変えず、英語UIでは登録済みの欧文表記、日本語UIでは登録済みの日本語表記を優先する。別名に言語指定がない旧データは文字種による表示上の優先であり、英訳・原語の宣言ではない。該当表記がなければ原名を残す。URLや識別子だけの候補は名前として選ばない。説明・根拠・ユーザーの自由文をこの方法で翻訳しない。

旧KGのsummaryにも既存の別名を任意で返し、名前が必要な画面で再取得を増やさない。固定の開始例は、既存KGにも登録されている別表記を持たせる。選択callbackと保存は元のEntityを使う。新共通原本の検索結果では、登録済み訳文を本文・名前・説明へ接続する。新共通原本のGraphでは確認済み訳名を優先し、旧KGの通常Graphでは登録済みの別表記を利用する。旧KGの全ての翻訳を通常Graphへ投影する処理は、今回の別表記対応とは区別する。

## テーマの版更新で英訳が消える問題

Theme構成版が変わっても、原文が全ての中間版で同一の項目は、確認済みの既存訳文を表示に利用できる。対象はThemeのタイトル・説明・年表見出し等の個別文字列。新しい訳文版の登録やAI送信は行わず、返す訳文は元のID・原文版を保持する。表示対象だけを`displayTarget`で別に示す。

現在版と訳文が参照する旧版の公開認可・原文hashを既存readerで確認する。原文編集／編集後の復元、言語変更、年表軸の削除、内容版欠落では再利用しない。現在版用の訳文が停止中なら旧訳へ戻さず、新しい旧版の訳文が停止中でも、それより古い訳を復活させない。DB・private内容は更新しない。

TOPのSSR・refresh、紹介／新着／検索／関連テーマ、中央のテーマ・年表表示が同じ公開読取を使う。テーマ検索は原文と公開・利用可能な訳文を照合し、名前順は表示言語のタイトルで並べる。

## 保存・公開の境界と制約

`displayTarget`付きの表示用継承は通常閲覧専用で、canonicalな訳文として新しいCapsuleの固定断面へ混ぜない。既存のCapsule・共有版・本人の題名／メモは変えない。直接対応する訳文を固定する既存契約も維持する。旧版に対応する訳文を、新版用の翻訳と偽って保存・公開しない。

一般の投稿本文、原資料の題名／引用、ユーザー表示名、外部広告はUIラベルとは異なる。訳文がない知識を英語であるかのように装わず、原文を保持する。今回、全登録知識の新しい訳文生成やAI利用枠の拡張は行わない。掲載内容の原文が実際に更新された場合は、新しい内容用の訳文を登録する必要がある。
