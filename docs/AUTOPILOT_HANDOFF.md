# 自動開発チェックポイント
- 状態：完了（複数の探索途中を保存・選択・再開・管理するローカルprototype。人間受入とは別）
- 目的：別の調査を始めても以前の枝と配置を失わず、名前を選んで続きを進める。
- 前回の1件保存・JSON持ち運びは完成済み。今回は最大10件へ拡張し、入口の統合は次に残した。
- 現在の探索を新規追加でき、名前・保存時刻付きの一覧から1件を選んで再開する。
- 置換ボタンは対象名を明示。削除は名前の確認と取消を挟み、削除後に他の保存を自動選択しない。
- 同じ保存キーをcollection v2へ拡張。各要素と専用JSONは従来の途中保存v1を維持する。
- 旧1件は読むだけでは書き換えず、最初の追加・置換成功時に引き継ぐ。保存失敗では元のv1を保持。
- 各保存40ページ・400枝／座標・100,000 bytes、一覧10件。満杯でも選択した1件の置換・削除は可能。
- 書込前に最新一覧を確認し、対象以外と別タブの追加を保持。置換・削除対象のUUID消失は拒否する。
- 別タブで選択版が変わると再選択を求める。localStorageの完全同時書込みは後勝ちの限界が残る。
- JSONは選択した1件を書出し、既定で新しい1件として読込。置換は対象選択とチェック後のファイル確認が必要。
- 取込ごとに新UUIDを付与。確認中の対象変更・消失、遅延読込、10件超過、破損・未知形式を拒否する。
- 再開の現在データ取得、閉鎖／休止枝、配置、原子的な切替、失敗・中止、直前復帰は既存契約を維持。
- 採用契約：docs/design/LOCAL_SAVED_WORKSPACE.md。旧版へ戻す場合は各v1 JSONを控え、空の別保存領域へ読込。
