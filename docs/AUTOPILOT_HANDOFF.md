- 状態：完了・2026-10-10共有失効後の本人投稿一覧・撤回。人間受入・実公開の完了ではない。
- 目的：リンクが失効しても、自分の発言を探して取り消せるようにする。
- 旧版再閲覧は完了済み。会員Capsuleへの新参照追加・版差分と比較し、既存撤回APIへ辿れない障害を優先した。

- 失効した共有画面→会員画面→自分の投稿→確認撤回→reloadを接続。会員画面からも直接開ける。
- GET /api/member/postsはsession本人・active・datasetで絞り、本文・投稿時版・日時・識別子だけを返す。
- Capsuleの題名・説明・KG参照・所有者情報・他人の投稿・共有tokenを返さず、失効した会話への権限も戻さない。
- owner停止・共有停止後もactiveな作者は管理可能。本人停止／匿名／期待User不一致は401、Capsule削除後は一覧から消える。
- 1ページ20件、新しい順のkeyset cursor。DBのmicrosecondとIDを保ち、同時刻・境界投稿削除でも続きへ進める。
- 撤回は既存DELETEを再利用。確認前は送信せず、結果不明は自動再送せず一覧を再確認する。
- 一覧は明示取得、永続storageなし。非表示・アカウント変更・復帰で再認可し、遅い応答を捨てる。表示中30秒ごとにも再確認。
- 本人一覧の401は親のprivate表示と処理中の保存を取消す。遅い成功応答で再表示せず、既存編集草稿を保持する。
- KG・凍結dataset・既存migration・共有tokenの権限は不変。新migrationなし。退会・運営非表示・公開運用の完成ではない。
