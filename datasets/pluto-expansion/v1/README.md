## 意味の境界

CONTRIBUTED_TOは制作参加の広い命題だけ。新しい作画・作者Roleは作らず、原表記をCitationに保持する。指定刊行物は既存publication scopeへ入れ、全巻・全版・その巻だけの担当を推論しない。会社の取締役／設立についてもAFFILIATED_WITHの広い関わりに限定し、役職・創業者IDを構造化した意味にはしない。会社設立日や連載期間をClaim.periodへ転記しない。

漫画とアニメ・キャラクターを混ぜない。MASTERキートンとReマスター、手塚プロダクションと虫プロは別対象。作品の出版社から作者所属を生成しない。PLUTO→鉄腕アトムの原作・派生関係は資料上検討できるが現predicateに置換せず、手塚治虫→PLUTOの直接制作Claimも作らない。

原資料に画・著があっても現行Role語彙に対応値がないため、Graphは「制作に関わった」のfallbackになる。資料に具体性がないのではなく、未構造化の語彙をCitationで保持している状態。取締役／設立も同様。表示だけで新Roleを補完しない。直接の作品派生・家族は現モデルに未実装で、今回の追加で解決したとはしない。
