# 浦沢直樹周辺・少数実データパイロット v1

凍結した読み取り用データ。5人物・3漫画作品、制作関与8 Claimと人物間の影響1 Claim、4 Source・9 Citation。世界全体や各人物の全経歴を表すものではない。

- ledger.json：正本となる収集・受入台帳。固定UUID、名称の言語と出所、QID照合、役割の原表記、引用対象の巻・版・ISBN、資料の限定、受入理由と保留を保持。
- raw/：8 Entityの取得済みWikidata JSON。labels・aliasesだけでなく元のstatement・qualifier・reference等を取得時のまま保存。関係のSourceとしては使わない。CC0-1.0。
- data.json：ledgerから生成した現行domain schemaへの投影。直接編集しない。
- manifest.json：データ版と変換版、ledger・raw・dataのSHA-256。生成時刻を毎回変えないので再生成は同じ結果になる。

`npm run pilot:prepare`でオフライン生成、`npm run pilot:validate`で原取得hash・revision・QID・名称・型・引用・出力整合を検査する。外部サイトへ再アクセスする処理は含まない。元資料の全文・画像は含めず、確認した事実・限定と必要な短い引用を保持する。WikidataのCC0は参照先出版社・記事の利用条件へ波及しない。

公開するClaimの根拠は小学館の商品情報2件、講談社の商品情報1件、関東弁護士会連合会の本人インタビュー1件。巻の発売日・取材日・Web公開日・関与期間は区別し、公開日と関与期間は不明のままにした。全巻への同一役割の適用は主張しない。

Q11264988は日本語labelが「きむらはじめ (漫画原作者)」、aliasが「勝鹿北星」。出版社で確認した名を表示名とし、Wikidataの他の筆名を検索aliasへ自動追加していない。PLUTOは漫画Q1197216で、惑星・アニメと区別した。

内容に変更が必要なら差分と理由をレビューし、新版として残す。v1の確認記録を失わせず、閲覧中のDBへライブ更新しない。現在の投入処理は更新基盤ではなく同じ確定内容の冪等投入に限定する。
